3. [**Friday AI Voice Assistant.**](https://github.com/d33p0st/friday "Friday Source Code Link")

    A voice assistant with natural language processing inspired

4. [**Pasta-Man 3-layered Password Manager.**](https://github.com/d33p0st/pasta-man "Pasta-Man Source Code Link")

    Pasta-Man was a hack-a-thon (FOSSit'2024) project that was
    as the top 5 by the judges. Pasta-Man is a password manager
    that has a triple layer encryption architecture with user
    features such as themes, tag-and-search, and copy to
    clipboard.
5. [**Detecteff.**](https://github.com/d33p0st/detecteff "Detecteff Source Code Link")

    Detecteff (or detective) is a duplicate file searcher and deleter. Seems like pretty basic right? But Detecteff
    searches for duplicate files with the same efficiency no
    matter the number of files in the given environment.
6. [**Ransomware for testing anti-ransomware mechanisms on macOS.**](https://github.com/d33p0st/test-ransomware "test-ransomware Source Code Link")

    A Ransomware with full control over which files to target and how to encrypt along with kill protection to avoid
    basic reverse engineering.
7. [**Python Rust Mix Build GitHub Action.**](https://github.com/marketplace/actions/python-rust-mixed-project-build-test "GitHub Market Place Link for this action")

    Python-Rust-Mix-Build is a GitHub Action for building and testing projects that are made using a mixture of Rust and Python programming language (Typically that uses `pyo3` crate for creating python bindings in Rust and `maturin` for
    compiling as whole).
8. [**Python Project Structure GitHub Action.**](https:://github.com/d33pster/python-project-structure "GitHub Source Code Link for this action")

9. [**WebRep: A Tool to footprint any webapp or website.**](https://github.com/d33pster/WebRep "Source Code Link")

    This is web foot-printing tool that fetches website/webapp

10. [**Social Media on a BlockChain (Simulation).**](https://github.com/d33pster/socialmedia-blockchain "Source Code Link")

11. [**ProcessPlot: An Application that imitates Task Manager but written in Python.**](https://github.com/d33pster/ProcessPlot "Source Code Link")
